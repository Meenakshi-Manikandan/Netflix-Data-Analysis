
# Netflix Data Analysis Using Python

## Project Overview
This project explores Netflix movies and TV shows using Python.

## Objectives
- Analyze content by genre.
- Explore country-wise content distribution.
- Analyze ratings.
- Compare Movies and TV Shows.
- Understand year-wise content growth.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Insights and Findings
